# Contributing

Contributions that improve explanations, input validation, tests, or offline lab examples are welcome.

1. Fork the repository and create a branch for your change.
2. Keep Python code readable and dependencies minimal.
3. Use synthetic passwords and hashes in examples and tests.
4. Run `python -m unittest discover -s tests -v` from the project root.
5. Open a pull request explaining the change and how you tested it.

Do not submit private hashes, passwords, capture files, or cracking results.
